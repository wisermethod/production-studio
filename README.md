# Production Studio

A WISER plugin for producing and editing video, training videos first: scripts written for ear and eye, narration in your own cloned voice, screen walkthroughs, animation, editing and publishing. No skills or experts have been built yet.

## Install

Point your harness at this repository as a plugin root, or add the repository as a marketplace and install `production-studio@wiser-method-production-studio` from its catalog.

Work lands in the working folder you attach, never in this repository.
